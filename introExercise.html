Mediated Expression : Intro Exercise

RMIT Digital Media Studio 2610

This is the intro exercise instructions from week 1 class 1. It assumes you've set up your GitHub repository, created the index.html file and run the "!" emmet template as explained here.

  1. Inside of your body element on a new line write a new h1 element. h1 stands for heading 1, usually used to give a title to a page. Inside of the tags write your web page's title like in the example below.
  2. Next we want to write in some answers to the following introduction questions:
    1. What is your full name, preferred name and pronouns?
    2. Where are you from?
    3. What brought you to the Digital Media program?
    4. What is your favourite emoji?
    5. What expressive software are you most comfortable using?
    6. What do you usually create with it?
    7. What is your experience with coding?
    We could format this text on our page in multiple ways, but for now let's make it as a paragraph by writing it inside a new p element (p stands for paragraph). Let's add it to the body of your page below the h1 like in the example below.
  3. Inside of your body element on a new line write a new h1 element. h1 stands for heading 1, usually used to give a title to a page. Inside of the tags write your web page's title like in the example below.
