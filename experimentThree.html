Mediated Expression : Experiment Three

RMIT Digital Media Studio 2610

Mapping Experiment

Brief:

Experiment with a novel input mechanism to change the colour of shape generated from your Konva template. This can use any of the HTML input elements except for the color input.

While you can style your input, the main focus should be on experimenting with creative mapping and value interpolation.

Instructions:

  1. In your file explorer find the konvaTemplate folder for the project folder created together in class. Copy this folder into your studioWorkIndex website folder and rename it "mappingDesignExperiment".
  2. We need to do some quick cleanup to make this work properly.
    1. First delete the ".idea" folder inside of this new feedbackDesignExperiment folder not the studioWorkIndex folder (only there on WebStorm).
    2. Then change the names of the style.css, and main.js to something specific like "mappingStyle.css" and "mappingMain.js".
    3. You'll also have to double-check the link and script import tags in the index.html file (in the feedbackDesignExperiment folder) to make sure they reference the new name.
    4. You can also delete the reset.css file inside of feedbackDesignExperiment and update the link href to "../reset.css" so it can find your reset inside of the main folder.
  3. Add a link to your experiment on your work index home page using an a element. The href should be "./mappingDesignExperiment".
  4. Choose an input element with any type except for color. Look at the kind of information stored within its value attribute, and design a way to interpolate it into a color value. Use code commenting to sketch out the logic before implementing it using JavaScript.
  5. Create a new function that takes the input's value when changed, interpolates it into a usable CSS color value , and then sets the circleColour variable.
  6. Remember there are many ways to write a colour value, but you should test that your input will always produce a verified value.
  7. Make sure to add code comments in the appropriate places, giving brief detail to your design choices. For example if you choose to use the date input to select your colour, which part of the date value you decided to use, and how you mapped that to a CSS color value.
  8. This experiment is hard!!! Try your best to get it working, but if you run into errors or issues at least make sure to at least document your intended logic for changing one value into another as a comment.
  9. Finally don't forget to check your work in browsers - both Firefox and Chrome if you can.
