Mediated Expression : Experiment One

RMIT Digital Media Studio 2610

Information Design Experiment

Brief:

Complete the information design for the two remaining control sliders on the simple synthesizer. This should include icons for either end of the range, custom CSS for the range input, and can optionally include a text label.

Unlike the first slider, which is clearly controlling the volume, the other two control sliders functionality is intentionally composite. Try to experiment with different modes of signification that don't focus on a strict accuracy of description, but may instead encourage different modes of user interaction.

Instructions:

  1. Navigate to the Week 2 module, and download the informationDesignExperiment.zip file. Unzip the file and copy the folder into your studioWorkIndex website folder.
  2. Add a link to your experiment on your work index home page using an a element. The href should be "./informationDesignExperiment".
  3. Follow the in class example for the volume slider information design, and then experiment with adding icons and text labels using the same process for the two remaining sliders.
  4. You can create your own icons, use existing icon sets with proper licences and attribution, emojis or unicode characters .
  5. You can style the sliders themselves using this guide or this CSS generator.
  6. You can additionally modify the global CSS styles of the page if you wish - an easy place to start is changing out the custom variables (--col01 etc) at the top of the file.
  7. Make sure to add code comments in the appropriate places, giving brief detail to your design choices. Your design doesn't have to use custom components, but you need to justify the choices you've made. For example if you choose to use emojis, add in a comment about why these particular emojis.
  8. Once you are finished publish the repository using Netlify. If you need a reminder of how this works check out the Setup Guide
  9. Finally don't forget to add a link to your experiment to your Studio Work Index.
