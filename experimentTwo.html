Mediated Expression : Experiment Two

RMIT Digital Media Studio 2610

Feedback Experiment

Brief:

Style and add feedback to your single button synthesizer to make it an engaging experience. While you can add additional HTML elements, focus on experimenting with what might be added using CSS and JavaScript.

Instructions:

  1. In your file explorer find the toneTemplate folder for the project folder created together in class. Copy this folder into your studioWorkIndex website folder and rename it "feedbackDesignExperiment".
  2. We need to do some quick cleanup to make this work properly. First delete the ".idea" folder inside of this new feedbackDesignExperiment folder (only there on WebStorm). Then change the names of the style.css, and main.js to something specific like "feedbackStyle.css" and "feedbackMain.js". You'll also have to double check the link and script import tags in the index.html file (in the feedbackDesignExperiment folder) to make sure they reference the new name. You can also delete the reset.css file inside of feedbackDesignExperiment and update the link href to "../reset.css" so it can find your reset inside of the main folder.
  3. Add a link to your experiment on your work index home page using an a element. The href should be "./feedbackDesignExperiment".
  4. Modify the existing CSS and JavaScript files to add a general layout/style, and then add your feedback.
  5. Think about how the button click can be broken down into discrete parts. For CSS this includes the :hover, :active and :focus pseudo-classes. For JavaScript eventListeners this includes the mouseenter, mousemove, mouseleave, mouseup, click and double click events. You don't have to use all of these, but they offer different information and opportunities for designing feedback.
  6. Make sure to add code comments in the appropriate places, giving brief detail to your design choices. Your design doesn't have to use custom components, but you need to justify the choices you've made. For example if you choose to use a CSS animation to spin your button, discuss why you chose to do so, and details like what influenced the choice of rotational speed.
  7. Finally don't forget to check your work in browsers - both Firefox and Chrome if you can.
