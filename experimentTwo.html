Mediated Expression : Experiment Two

RMIT Digital Media Studio 2610

Feedback Experiment

Brief:

Style and add feedback to your single button synthesizer to make it an engaging experience. Don't add any additional HTML elements, but instead experiment with CSS and JavaScript.

Instructions:

  1. Create a new repository using the toneTemplate-DMS2610 you created in class as a template. Make sure you're the owner, give it a descriptive name, and make sure it's set to public.
  2. Modify the existing CSS and JavaScript files to add a general layout/style, and then add your feedback.
  3. Think about how the button click can be broken down into discrete parts. For CSS this includes the :hover, :active and :focus pseudo-classes. For JavaScript eventListeners this includes the mouseenter, mousemove, mouseleave, mouseup, click and double click events. You don't have to use all of these, but they offer different information and opportunities for designing feedback.
  4. Make sure to add code comments in the appropriate places, giving brief detail to your design choices. Your design doesn't have to use custom components, but you need to justify the choices you've made. For example if you choose to use a CSS animation to spin your button, discuss why you chose to do so, and details like what influenced the choice of rotational speed.
  5. Once you are finished publish the repository using Netlify. If you need a reminder of how this works check out the Setup Guide
  6. Finally don't forget to add a link to your experiment to your Studio Work Index.
